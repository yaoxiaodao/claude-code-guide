# 第五章：读懂代码库

::: tip 学习目标
学完这章，你会让 Claude 帮你分析和理解现有代码。
:::

## 为什么让 AI 读代码更快？

想象你要接手一个陌生人的项目：

- 自己读：可能需要几天
- 让 Claude 读：几分钟就能了解大概

Claude 可以快速理解代码结构，帮你回答"这个项目是做什么的"、"某个函数在哪里"等问题。

## 告诉 Claude 读哪个文件

### 进入项目目录

```bash
cd 你的项目路径
```

### 启动 Claude

```bash
claude
```

### 问 Claude

```
请分析一下这个项目的结构
```

Claude 会读取目录下的文件，告诉你项目的基本情况。

## 问更具体的问题

### 问单个文件

```
这个 main.py 的主要功能是什么？
```

### 问某个函数

```
帮我理解 utils.py 里的 helper 函数
```

### 问整体架构

```
这个项目是怎么组织的？有哪些主要模块？
```

## 实际案例

假设你接手了一个博客项目：

1. **问**：这个项目是做什么的？
2. **Claude 答**：这是一个博客系统，使用 Python Flask 框架...
3. **问**：用户认证是怎么实现的？
4. **Claude 答**：在 `auth.py` 文件里，使用 JWT token...

## 前置知识

知道什么是代码文件（.py, .js 等）。

## 常见问题

**Q: Claude 读错了？**

A: 确认你在正确的目录下，用 `pwd` 查看当前位置。

**Q: 大项目分析很慢？**

A: 先指定具体文件，不要一次性分析整个项目。

## 练习题

把你的某个旧项目扔给 Claude，让它帮你分析结构。
