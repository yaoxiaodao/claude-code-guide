# 第七章：多轮对话技巧

::: tip 学习目标
学完这章，你会通过多轮对话一步步完善代码。
:::

## 为什么多轮对话更有效？

想象你要建一座房子：

- **一次性描述**：给我建一座房子 → 出来的可能不是你想要的
- **一步步来**：先打地基 → 地基好了，继续砌墙 → 墙好了，继续装修 → 每一步都能调整

多轮对话就是这种方式，让 Claude 一步步帮你完善。

## 场景演练：做一个待办事项

### 第一轮：基础结构

```
帮我写一个待办事项的基本结构
```

Claude 会给你一个基本框架。

### 第二轮：添加功能

```
添加"标记完成"功能
```

Claude 在现有基础上继续开发。

### 第三轮：添加保存

```
添加"保存到文件"功能
```

Claude 继续完善。

## 上下文的作用

Claude 记得对话历史，所以：

- 你不需要重复之前说的话
- 可以随时问"现在的进度怎么样了"

## 什么时候开新对话？

- 对话太长了（超过几百条）
- 换了一个完全不相关的任务
- 想重新开始

## 清空对话

```
/clear
```

输入这个命令可以清空对话历史。

## 前置知识

会基本的对话操作。

## 常见问题

**Q: Claude 忘了之前的对话？**

A: 超过一定长度可能遗忘，可以开新对话并简要描述背景。

**Q: 对话乱了？**

A: 输入 `/clear` 清空重来。
