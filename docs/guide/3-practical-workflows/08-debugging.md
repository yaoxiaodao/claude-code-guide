# 第八章：调试和错误处理

::: tip 学习目标
学完这章，你会让 Claude 帮你找出 bug 并修复。
:::

## 把错误信息粘贴给 Claude

### 1. 运行你的代码

```bash
python hello.py
```

### 2. 复制错误信息

把完整的错误信息复制下来。

### 3. 粘贴给 Claude

```
帮我看看这个错误：

[粘贴错误信息]
```

Claude 会告诉你：
- 错误是什么
- 哪一行出了问题
- 怎么修复

## 修复步骤

### Claude 解释后

让 Claude 直接修复：

```
请帮我修复这个问题
```

### 运行确认

修复后重新运行代码，确认错误消失了。

## 常见 Python 错误

| 错误 | 含义 |
|------|------|
| `SyntaxError` | 语法错误，括号、引号没配对 |
| `NameError` | 变量名写错了 |
| `TypeError` | 类型不匹配 |
| `IndexError` | 数组索引超出范围 |

## 调试心态

::: tip 提示
AI 辅助不是万能的。
:::

Claude 可能：
- 给出的修复方案不正确
- 没有找到真正的问题
- 修复一个 bug 引入了新的 bug

**永远要先理解问题，再接受修复。**

## 前置知识

写过能运行的代码。

## 常见问题

**Q: 同样的错误修完又出现？**

A: 可能需要从根本上重构，不只是表面修复。

**Q: Claude 修错了？**

A: 用 `/undo` 撤销，或手动回滚到之前的版本。

1. 故意写一个有 bug 的代码
2. 让 Claude 帮你找出来并修复
