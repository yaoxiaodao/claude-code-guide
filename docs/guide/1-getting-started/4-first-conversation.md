# 第四章：首次对话

::: tip 学习目标
学完这章，你会学会和 Claude Code 对话的基本方式。
:::

## 启动对话

### 1. 打开终端

### 2. 输入 claude

```bash
claude
```

### 3. 你好！

直接输入中文和它打招呼：

```
你好，Claude!
```

Claude 会用中文回复你。

## 退出对话

两种方式：

1. 输入 `exit` 并回车
2. 按 `Ctrl + C`

## 怎么问问题效果最好？

### 模糊 vs 具体

| 效果不好的问法 | 效果好的问法 |
|--------------|-------------|
| "代码有问题" | "这个函数报 TypeError: Cannot read property 'x' of undefined" |
| "帮我看看" | "帮我看看这个文件里的 `calculateSum` 函数" |
| "能帮我吗" | "能帮我写一个计算两个数之和的函数吗？" |

越具体，Claude 回答越准确。

## 第一次实战：解释一个文件

### 1. 创建一个测试文件

```bash
# 创建一个文件夹（如果需要）
mkdir test-project
cd test-project

# 创建文件
echo 'print("Hello World")' > hello.py
```

### 2. 让 Claude 解释它

回到 Claude Code（如果退出了，重新输入 `claude`），问：

```
帮我解释一下 hello.py 这个文件做了什么
```

Claude 会告诉你这个文件的含义。

## 常用提问示例

### 理解代码库

Claude 会按需读取你的项目文件，你不必手动添加上下文。试试这些问法：

```
这个项目是做什么的？
```

```
这个项目使用什么技术？
```

```
主入口点在哪里？
```

```
解释一下文件夹结构
```

### 询问 Claude Code 自身功能

```
Claude Code 能做什么？
```

```
我如何在 Claude Code 中创建自定义 skills？
```

```
Claude Code 可以与 Docker 一起工作吗？
```

### 其他常见问题

```
帮我解释一下 hello.py 这个文件
```

```
这段代码哪里有 bug？
```

```
帮我写一个计算两个数之和的函数
```

## Claude 的回答格式

Claude 的回答通常包含：

1. **解释**：它在做什么
2. **代码**（如果有）：实际的代码块
3. **建议**（如果有）：还有什么可以改进的

## 前置知识

完成前三章的安装和配置。

## 常见问题

**Q: Claude 回答很慢？**

A: 正在生成回复，稍等即可。

**Q: 回答被截断了？**

A: 输入"继续"，让它继续说完。

**Q: 答非所问？**

A: 换个问法，越具体越好。
