# 第六章：编辑和创建代码

::: tip 学习目标
学完这章，你会让 Claude 帮你创建新文件和修改现有文件。
:::

## 两种编辑方式

1. **直接生成**：让 Claude 写完整代码，你复制使用
2. **渐进式修改**：让 Claude 直接修改你的文件

## 创建新文件

### 直接问

```
帮我创建一个 sum.py，实现加法函数
```

Claude 会给你完整的代码。

### 复制使用

把代码复制到你的编辑器，保存文件。

## 修改现有文件

### 使用 /edit 命令

```
/edit
```

Claude 会进入编辑模式。

### 描述你要改什么

```
把这个函数的返回值从 int 改成 float
```

Claude 会生成修改后的代码，询问你是否接受。

### 接受或拒绝

- **Apply**：接受修改
- **Reject**：拒绝，重新生成
- **部分接受**：可以手动微调

## 一定要审查代码！

::: warning 重要
Claude 写的代码一定要看一遍再使用！
:::

Claude 可能：
- 有 bug
- 不符合你的编码习惯
- 有安全风险

你是最后把关的人。

## 如何要求重写

如果 Claude 写的不好：

```
不要这个方案，换一个

或者

这个不对，请用 XXX 方式重写
```

## 前置知识

知道代码文件存在哪。

## 常见问题

**Q: Claude 写的代码报错？**

A: 把错误信息粘贴给 Claude，让它修复。

**Q: 不想用 Claude 写的？**

A: 直接说"不要这个方案，换一个"。

**Q: 怎么只接受部分修改？**

A: 可以手动微调，Claude 不会介意。

2. 让它添加"添加学生"和"查看成绩"功能
