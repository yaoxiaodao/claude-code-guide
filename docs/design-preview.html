首次对话 - Hello World

这一章你会学会和 Claude Code 对话的基本方式。这是你们第一次"对话"， 就像认识一个新朋友。不用担心说错，Claude 很耐心。

启动对话

打开终端，输入 claude，回车：

~/projects/my-app$ claude
✓ Connected to Claude
You can now start chatting!

说"你好"

现在你可以直接输入中文，Claude 会用中文回复你：

terminal 
> 你好，Claude!

你好！很高兴认识你。我是 Claude，一个 AI 编程助手。
我可以帮你读代码、写代码、解释代码，或者一起讨论技术问题。
有什么我可以帮你的吗？
💡 小提示
Claude 会记住对话的上下文，所以你可以像和同事聊天一样， 一步一步地完成一个任务。

创建一个测试文件

让我们创建一个简单的 Python 文件来测试：

python
