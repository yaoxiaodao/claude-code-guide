# 第六章：编辑和创建代码

::: tip 学习目标
学完这章，你会让 Claude 帮你创建新文件和修改现有文件，掌握安全编辑的技巧。
:::

## 两种编辑方式

1. **直接生成**：让 Claude 写完整代码，你复制使用
2. **直接修改**：描述要改什么，Claude 直接修改你的文件

## 创建新文件

### 直接描述需求

```
帮我创建一个 sum.py，实现加法函数
```

Claude 会给你完整的代码。

### 复制使用

把代码复制到你的编辑器，保存文件。

## 修改现有文件

Claude Code 没有专门的 `/edit` 命令。正确的做法是：**直接描述你想怎么改**。

### 描述你要改什么

不需要记住任何命令，直接说人话：

```
把这个函数的返回值从 int 改成 float
```

```
帮我把 auth.py 里的密码加密换成 bcrypt
```

### Claude 会做什么

1. 分析你的代码
2. 生成修改后的代码（展示 diff）
3. 等待你确认

### 确认或拒绝

- **approve**：Claude 写入文件
- **deny**：Claude 停止，等待你换一种描述方式

```
好，改吧        → approve
不用这个方案    → deny，换一种说法
```

## 撤销与回退

### `/rewind` — 回退到之前的状态

Claude Code 没有 undo 命令，但有更强大的 `/rewind`。

```
/rewind
```

**`/rewind` 会同时回退两件事：**
1. **对话历史** — 回到之前的某个对话节点
2. **文件状态** — 文件也会恢复到那个节点的样子

如果改坏了文件，直接 `/rewind` 就能一起退回去，比 Git 逐个文件还原更方便。

### `/retry` — 重新生成

如果对结果不满意，让 Claude 重新生成：

```
/retry
换个方案试试
```

### 编辑后验证

编辑完成后，让 Claude 检查：

```
帮我检查一下修改是否正确，有没有引入新问题
```

## 一定要审查代码！

::: warning 重要
Claude 写的代码一定要看一遍再使用！
:::

Claude 可能：
- 有 bug
- 不符合你的编码习惯
- 有安全风险

你是最后把关的人。

## 批量编辑

### 一次性修改多个文件

```
帮我重构 auth 模块：
1. User 模型添加 email 字段
2. login 函数改用 bcrypt 加密
3. 更新相关测试
```

### 编辑后验证

编辑完成后，让 Claude 检查：

```
帮我检查一下修改是否正确，有没有引入新问题
```

## 如何要求重写

如果 Claude 写的不好：

```
不要这个方案，换一个

或者

这个不对，请用 XXX 方式重写
```

## 常见问题

**Q: Claude 写的代码报错？**

A: 把错误信息粘贴给 Claude，让它修复。

**Q: 不想用 Claude 写的？**

A: 直接说"不要这个方案，换一个"。

**Q: 怎么只接受部分修改？**

A: 可以手动微调，Claude 不会介意。

**Q: 如何回退到之前的版本？**

A: 使用 `/rewind` 回退对话和文件到之前状态，或从 Git 恢复文件。

**Q: Claude 会覆盖我手动改的文件吗？**

A: 不会，Claude 只在你明确批准后才会写入文件。

**Q: 能查看文件编辑历史吗？**

A: 通过 Git 可以查看，Claude 的每次编辑都对应一个 commit。

## 练习题

1. 让 Claude 帮你写一个"学生成绩管理"程序
2. 让它添加"添加学生"和"查看成绩"功能
3. 故意让它写一个有问题的代码，然后用 `/rewind` 撤销
