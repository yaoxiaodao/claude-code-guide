# 第九章：代码审查和优化

::: tip 学习目标
学完这章，你会让 Claude 帮你审查代码质量并给出优化建议。
:::

## 代码审查是什么？

代码审查是检查代码质量的过程，找出：
- 潜在 bug
- 安全风险
- 可读性问题
- 性能问题

## 让 Claude 审查代码

### 审查整个文件

```
请审查这个文件的代码问题
```

### 问优化建议

```
有哪些地方可以优化？
```

## Claude 常发现的问题

1. **命名问题**：变量名 `x`、`temp` 不够清晰
2. **重复代码**：多处重复相似的逻辑
3. **安全问题**：SQL 注入、密码明文等
4. **性能问题**：循环效率、数据库查询

## 逐个讨论

不要一次接受所有修改建议，逐个问：

```
先修复命名问题，其他的先不动
```

这样你可以控制改动的范围。

## 常见问题

**Q: Claude 说的对不对？**

A: 你是最终决策者，保持批判思维。

**Q: 优化建议太多了？**

A: 优先处理高风险问题。

## 练习题

找一段旧代码让 Claude 审查，并实施它的优化建议。
