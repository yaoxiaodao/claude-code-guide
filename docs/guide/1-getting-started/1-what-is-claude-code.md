# 第一章：Claude Code 是什么

::: tip 学习目标
学完这章，你会理解 Claude Code 能做什么、不能做什么，以及在国内用什么方式才能用上它。
:::

## 它是住在你电脑里的 AI，不是一个网页

Claude Code 是 Anthropic 出的 AI 编程助手。和网页版聊天最大的区别：**它直接在你的电脑上干活**——读你的文件、改你的代码、运行命令。

| | 网页版 Claude（claude.ai） | Claude Code |
|---|---|---|
| 在哪运行 | 浏览器 | 你自己的电脑 |
| 能看什么 | 你粘贴给它的内容 | 整个项目文件夹 |
| 能做什么 | 回答、写作、分析 | 直接读写文件、跑命令、改代码 |
| 适合 | 一问一答 | 需要多步骤、要动真文件的活 |

## 四种打开方式，从最简单的开始

Claude Code 现在不止一种形态，你按自己的习惯选一个就行：

1. **终端（CLI）** — 本教程的主角。一个黑框框，打字对话。功能最全，所有新特性都先出现在这里
2. **桌面应用** — 装个 App，有图形界面，能同时开多个会话，不用记命令
3. **VS Code / JetBrains 插件** — 在编辑器里直接用，改动直接显示成 diff
4. **网页版（云端）** — 浏览器里跑，不用装任何东西，适合临时任务

本教程以**终端**为主，因为它的概念最通用：学会终端，其他几种形态基本不用重新学。

## Claude Code 能做什么？

它是一个 AI 编程助手，但能做的事远不止编程。

### 编程相关

- **读代码**：帮你理解一个陌生项目的结构
- **写代码**：创建新文件或修改现有代码
- **解释代码**：用自然语言解释代码在做什么
- **调试问题**：帮你找出 bug 并修复
- **审查代码**：`/code-review` 直接检查你的改动
- **辅助 Git**：写 commit message、处理合并冲突、解释别人的改动

### 文档编辑

Claude Code 擅长处理各种文档工作：

- **Word 文档**：写报告、写文档、润色文字、总结内容
- **Excel 表格**：分析数据、写公式、生成图表
- **PPT 制作**：规划演示结构、写内容、调整格式
- **Markdown 写作**：写博客、写文档、写邮件（.md 是它最顺手的格式）

### 日常重复性工作

- **批量重命名文件**：按规则批量改文件名
- **整理文件夹**：自动归类、移动、清理重复文件
- **批量生成文本**：报告、邮件、模板内容
- **数据格式转换**：CSV 转 JSON、Excel 转数据库格式
- **日志分析**：从大量日志里提取关键信息

::: tip 小技巧
由于 Claude Code 能直接读写你的电脑文件，它特别适合需要**批量处理**或**多步骤自动化**的任务。这类活网页版 Claude 做不了，因为它碰不到你的硬盘。
:::

## 在中国大陆怎么用上它

这一步很多人卡住，先说清楚。Claude Code 本身是免费软件，但**用起来需要一个能调用 Claude 模型的账号**，有两条路：

| 方式 | 门槛 | 适合谁 |
|---|---|---|
| **官方账号**（Claude Pro/Max 订阅，或 Anthropic API Key） | 需要海外支付方式 + 网络能连上 Anthropic | 有海外信用卡、或有稳定网络的同学 |
| **第三方 API 中转**（国内中转服务商） | 支付宝/微信付款即可，网络直连 | 大部分国内用户 |

本站**第三章**会详细讲第二条路（用中转服务商），因为对国内用户门槛最低。如果你已经有官方订阅，装完直接运行 `claude` 按提示登录就行，可以跳过第三章。

::: warning 别被这件事劝退
账号配置只做一次，十分钟的事。真正需要学的是后面怎么和它对话、怎么让它干活。先花十分钟配好，剩下的都是收益。
:::

## Claude Code 不能做什么？

- **不能替你做决定**：最终决策权在你手里
- **不会读心术**：你需要清楚地描述你要什么
- **复杂 Excel/PPT 有上限**：基本编辑没问题，复杂格式和宏还是要你自己调整
- **不能保证 100% 正确**：它会犯错，尤其是它看不到的信息（比如你脑子里的部署流程）。看到改动先看一眼 diff 再接受

::: tip 关于"操作确认"
早期版本的 Claude Code 每一步都要你点确认。现在默认是**自动模式**（auto mode）：安全操作（读文件、跑测试）自动放行，危险操作（删文件、push 到远端）仍会被拦下问你。你随时可以按 `Shift + Tab` 切换这个行为。详见第十七章。
:::

## 和 ChatGPT / Copilot 的区别

| 工具 | 特点 | 适合场景 |
|---|---|---|
| ChatGPT / Claude 网页版 | 网页聊天，什么都能问 | 通用问答、写文章、分析数据 |
| Copilot | IDE 插件，边写边补全 | 写代码时逐行补全 |
| Claude Code | 在项目里工作的 AI，能读写文件、跑命令 | 理解整个项目、批量改代码、自动化 |

## 常见问题

**Q: Claude Code 要钱吗？**

A: 软件免费。要花钱的是模型调用：官方订阅按月付费，中转服务商按量付费（通常几块钱起步就能试）。

**Q: 不会命令行能学吗？**

A: 能。本教程从零教你终端的基本用法，真正要记的命令不到 10 个。

**Q: 我的电脑配置够吗？**

A: 够。它不占本地算力，所有推理都在云端。任何能上网的 Mac / Windows / Linux 电脑都能跑。

**Q: 会不会把我代码搞坏？**

A: 有两个保险：一是它改动前会显示 diff，二是 `/rewind` 能把代码和对话回滚到之前任意一个检查点。
