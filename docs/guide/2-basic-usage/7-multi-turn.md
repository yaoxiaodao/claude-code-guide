# 第七章：多轮对话技巧

::: tip 学习目标
学完这章，你会通过多轮对话一步步完善代码，并掌握会话管理技巧。
:::

## 为什么多轮对话更有效？

想象你要建一座房子：

- **一次性描述**：给我建一座房子 → 出来的可能不是你想要的
- **一步步来**：先打地基 → 地基好了，继续砌墙 → 墙好了，继续装修 → 每一步都能调整

多轮对话就是这种方式，让 Claude 一步步帮你完善。

## 场景演练：做一个待办事项

### 第一轮：基础结构

```
帮我写一个待办事项的基本结构
```

Claude 会给你一个基本框架。

### 第二轮：添加功能

```
添加"标记完成"功能
```

Claude 在现有基础上继续开发。

### 第三轮：添加保存

```
添加"保存到文件"功能
```

Claude 继续完善。

## 上下文的作用

Claude 记得对话历史，所以：

- 你不需要重复之前说的话
- 可以随时问"现在的进度怎么样了"

## 会话管理

### Token 限制

每个对话有 Token 限制（通常数万）。超过限制后：
- 早期对话可能被"遗忘"
- 响应会变慢

### 什么时候开新对话？

| 场景 | 建议 |
|------|------|
| 对话超过 50 条 | 开新对话 |
| 换完全不相关的任务 | 开新对话 |
| 想重新开始 | 开新对话 |
| 深入同一个任务 | 保持当前对话 |

### 高效交接

开新对话时，简要描述背景：

```
我在做一个 Flask 博客项目，已经：
1. 完成了用户认证（JWT）
2. 完成了文章 CRUD
3. 使用 PostgreSQL 数据库

现在要添加评论功能...
```

## 记忆系统

Claude Code 有持久记忆功能：

### 查看记忆

```
/memory
```

会显示当前已保存的记忆。

### 添加记忆

```
/memory
记住：这是一个 Vue 3 + Pinia 项目
```

### 记忆的作用

记忆让你不需要每次都重复背景信息：

```
第一次：记住这是 Next.js 项目
之后：直接说"帮我在 About 页面添加..."
Claude 会知道是 Next.js 项目
```

### 清除记忆

```
/memory clear
```

## 清空对话

如果对话乱了但想保持上下文：

```
/clear
```

这会清空对话历史，但**不会**清除记忆。

## 压缩上下文

对话太长时，Claude 可以压缩上下文：

```
/compact
```

会尝试精简历史记录，保留关键信息。

会基本的对话操作。

## 常见问题

**Q: Claude 忘了之前的对话？**

A: 超过一定长度可能遗忘。可以用 `/memory` 保存重要上下文，或开新对话并描述背景。

**Q: 对话乱了？**

A: 输入 `/clear` 清空重来。如果想保持一些信息，先用 `/memory` 保存。

**Q: 记忆和对话有什么区别？**

A: 记忆是持久的，跨对话存在。对话历史只在当前会话有效。

**Q: 怎么知道 Token 快用完了？**

A: 对话变慢、响应变短时可能接近限制。开新对话是更好的选择。

**Q: 能让 Claude 只记住特定的规则吗？**

A: 可以，用 `/memory` 添加精确的规则描述。

3. 对话太长时用 `/compact` 压缩上下文
