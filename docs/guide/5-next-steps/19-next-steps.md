## 继续深入的方向

### 方向一：成为 AI 编程重度用户

- **每天用一点** — 不用刻意学，日常遇到问题就问 Claude
- **记录好用的提示词** — 把你觉得好用的提示词模板收集起来
- **教给别人** — 教别人的时候你会理解得更深

### 方向二：探索 MCP 生态

- [MCP 官方文档](https://modelcontextprotocol.io/)
- [MCP 服务器社区列表](https://github.com/modelcontextprotocol/servers)
- 尝试连接更多外部工具（数据库、API、自动化工具）

### 方向三：自定义工作流

- 写自己的 Skill 扩展
- 配置 `.claude.json` 自定义行为
- 结合 CI/CD 自动化工作流

### 方向四：关注更新

Claude Code 每月都有新功能：

- 关注官方 Release Notes
- 关注 [GitHub Discussions](https://github.com/anthropics/claude-code/discussions)
- 加入中文社区讨论

## 常见问题

**Q: 感觉学了很多但还是不太会用？**

A: 很正常。AI 编程是技能，不是知识。看教程只能了解概念，真正的熟练需要大量实践。建议每天用它解决一个小问题，一周后就会有感觉。

**Q: 遇到 Claude 答非所问怎么办？**

A: 80% 的问题出在提示词。试着：
- 更具体地描述问题
- 提供更多上下文
- 把大任务拆成小步骤

**Q: 会不会被 AI 取代？**

A: 不会取代你，但会用 AI 的人会取代不会用的人。你已经在正确的路上。

**Q: 遇到 Claude 解决不了的问题怎么办？**

A: 把问题拆小、描述更具体、给它更多上下文。大部分问题都可以通过更好的提示词解决。
