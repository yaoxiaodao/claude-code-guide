## Problem Statement

创建一个系统的、从简到难的中文 Claude Code 教程，面向完全零基础的用户。核心解决现有教程"缺乏系统性"的问题，让用户学完后具备继续探索高级用法的基础。

## What Makes This Cool

让 AI 编程工具的入门门槛降到最低。不是堆砌功能清单，而是构建一条**平滑的学习曲线**，让每个初学者都能从头走到继续探索的那一步。

## Target User & Narrowest Wedge

**目标用户：** 高校学生、教师、刚入行的开发者——用过代码但没用过 AI 辅助编程工具的人

**最小可行内容（MVP）：**
1. 环境安装配置
2. API Key 获取与安全使用
3. 基础对话流程（读文件、改代码、解释代码）
4. 日常工作辅助场景（调试、代码审查）

## Constraints

- 全程中文
- 面向零基础，但需要有一定的编程基础（至少写过代码）
- 可扩展：模块化设计，方便后续添加内容
- 静态网站，便于托管和访问

## Approaches Considered

### Approach A: MVP 先跑（推荐）
- 5-7 个核心模块，每个模块 2-3 篇文章
- VitePress + GitHub Pages
- 2-4 周上线第一版
- 渐进扩展

### Approach B: 完整知识库
- 10+ 模块，覆盖所有内容
- Docusaurus + i18n
- 8-12 周完成初版

### Approach C: 交互式教程
- 文档 + 可运行练习题
- VitePress + GitHub Codespaces
- 4-6 周核心练习

## Recommended Approach

**方案 A（选择）：MVP 先跑**

原因：
1. 快速验证——2-4 周能看到实际效果
2. 符合"平滑曲线"的设计理念——先给最核心的内容
3. 降低维护压力——先上线，再迭代
4. 渐进扩展性——模块化设计确保后续添加不破坏结构

## Content Structure（MVP 模块）

每个章节包含：
- **学习目标**：学完这章能做什么
- **前置知识**：需要什么基础（几乎都是"会打字就行"）
- **操作步骤**：傻瓜式截图+命令
- **常见问题**：FAQ 提前预判
- **练习题**：学完马上练

### 第一章：Claude Code 是什么（10 分钟）

**学习目标：** 理解 Claude Code 能做什么，不能做什么

**内容大纲：**
- Claude Code 是命令行工具，不是网页聊天
- 它能：读代码、写代码、改代码、解释代码
- 它不能：替你运行代码（需要你确认）
- 和 ChatGPT / Copilot 的区别是什么

**前置知识：** 无

**操作步骤：** 无（纯概念）

**常见问题：**
- Q: Claude Code 要钱吗？A: 有免费额度，API Key 才收费
- Q: 不会命令行能学吗？A: 教程会从零教

---

### 第二章：安装 Claude Code（15-20 分钟）

**学习目标：** 在自己电脑上成功安装 Claude Code

**内容大纲：**
- 什么是终端/命令行
- Windows 用户：安装 Windows Terminal + Claude Code
- Mac 用户：使用终端 + Claude Code
- Linux 用户：直接安装
- 验证安装成功：`claude --version`

**前置知识：** 会开关电脑、会打字

**操作步骤（Windows 为例）：**
1. 下载 Claude Code 安装包（官网链接+百度网盘备链）
2. 双击安装，一路下一步
3. 打开 PowerShell 或 Windows Terminal
4. 输入 `claude --version`，看到版本号即成功
5. 截图确认

**常见问题：**
- Q: 提示"找不到命令"？A: 重启终端或重新安装
- Q: 杀毒软件报警？A: 信任该软件，或暂时关闭杀毒

**练习题：** 在终端输入 `claude --version` 并截图

---

### 第三章：获取和配置 API Key（20 分钟）

**学习目标：** 拿到 Anthropic 官方的 API Key，并配置到 Claude Code

**前置知识：** 会注册网站账号、有信用卡（可选）

**内容大纲：**
- 什么是 API Key，为什么需要它
- 注册 Anthropic 账号的步骤（截图版）
- 创建 API Key 的位置
- 如何安全保管 API Key（不要分享、不要提交到 GitHub）
- 配置到 Claude Code：`claude --local`
- 验证：输入 `claude` 看到对话界面

**操作步骤：**
1. 打开 anthropic.com官网
2. 点击 Sign Up 注册（可用 Google 账号）
3. 登录后进入 Console
4. 点击 API Keys → Create Key
5. 复制 Key（只会显示一次！）
6. 打开终端，输入 `claude` 按提示粘贴 Key
7. 看到 `You can now start chatting!` 即成功

**常见问题：**
- Q: API Key 要钱吗？A: 有免费额度，初期够用
- Q: Key 泄露了怎么办？A: 立刻在官网删除，重新生成
- Q: 看不到 Create Key 按钮？A: 可能账号没激活，检查邮箱

**练习题：** 成功在 Claude Code 里问"你好"并收到回复

---

### 第四章：首次对话 - Hello World（15 分钟）

**学习目标：** 学会和 Claude Code 对话的基本方式

**前置知识：** 完成前三章

**内容大纲：**
- Claude Code 的两种模式：对话模式 / 单命令模式
- 如何退出：输入 `exit` 或按 `Ctrl+C`
- 怎么问问题效果最好
- 第一次实战：让 Claude 解释一个简单文件

**操作步骤：**
1. 打开终端，输入 `claude` 进入对话
2. 输入"你好"
3. 创建一个测试文件 `test.py`：写入 `print("Hello World")`
4. 问 Claude："帮我解释这个文件做了什么"
5. 观察 Claude 的回答格式

**常见问题：**
- Q: Claude 回答很慢？A: 正在生成，稍等即可
- Q: 回答被截断了？A: 输入"继续"让它说完
- Q: 答非所问？A: 换个问法，越具体越好

**练习题：** 让 Claude 帮你写一个"计算两个数之和"的 Python 程序

---

### 第五章：读懂代码库（20 分钟）

**学习目标：** 学会让 Claude 分析和理解现有代码

**前置知识：** 知道什么是代码文件（.py, .js 等）

**内容大纲：**
- 为什么让 AI 读代码比你自己读更快
- 告诉 Claude 读哪个文件的语法
- 读懂整个项目的结构
- 案例：分析一个开源项目

**操作步骤：**
1. 进入项目目录：`cd 你的项目路径`
2. 启动 Claude：`claude`
3. 问："请分析这个项目的结构"
4. 问："这个 main.py 的主要功能是什么"
5. 问："帮我理解 utils.py 里的 helper 函数"

**常见问题：**
- Q: Claude 读错了？A: 确认你在正确的目录下
- Q: 大项目分析很慢？A: 先指定具体文件，不要一次性分析整个项目

**练习题：** 把你的某个旧项目扔给 Claude，让它帮你写 README

---

### 第六章：编辑和创建代码（25 分钟）

**学习目标：** 学会让 Claude 直接帮你写代码、修改代码

**前置知识：** 知道代码文件存在哪

**内容大纲：**
- 两种编辑方式：直接生成代码 / 渐进式修改
- 让 Claude 创建新文件
- 让 Claude 修改现有文件（Edit 模式）
- 如何审查 Claude 生成的代码（一定要看！）
- 怎么拒绝/要求重写

**操作步骤：**
1. 创建新文件：问"帮我创建一个 sum.py，实现加法函数"
2. 修改现有文件：问"把这个函数的返回值从 int 改成 float"
3. 使用 /edit 命令进入编辑模式
4. Claude 生成修改后，会询问你确认 Apply（接受）或拒绝

**常见问题：**
- Q: Claude 写的代码报错？A: 把错误信息粘贴给它，让它修复
- Q: 不想用 Claude 写的？A: 直接说"不要这个方案，换一个"
- Q: 怎么只接受部分修改？A: 可以手动微调，Claude 不会介意

**练习题：**
1. 让 Claude 帮你写一个"学生成绩管理"的程序
2. 让它添加"添加学生"和"查看成绩"功能

---

### 第七章：多轮对话技巧（20 分钟）

**学习目标：** 学会通过多轮对话完善代码

**前置知识：** 会基本的对话操作

**内容大纲：**
- 为什么多轮对话比一次性描述更有效
- 场景演练：一步步完善一个功能
- 怎么利用上下文（Claude 记得对话历史）
- 什么时候该开新对话

**操作步骤：**
1. 第一轮：让 Claude 写一个"待办事项"的基本结构
2. 第二轮：添加"标记完成"功能
3. 第三轮：添加"保存到文件"功能
4. 观察 Claude 如何在前面的基础上继续开发

**常见问题：**
- Q: Claude 忘了之前的对话？A: 超过一定长度可能遗忘，可开新对话并简要描述背景
- Q: 对话乱了？A: 输入 /clear 清空重来

**练习题：** 用多轮对话方式，让 Claude 帮你做一个"记账本"程序

---

### 第八章：调试和错误处理（25 分钟）

**学习目标：** 学会让 Claude 帮你找 bug 和修复错误

**前置知识：** 写过能运行的代码

**内容大纲：**
- 把错误信息粘贴给 Claude
- 让 Claude 添加日志定位问题
- 常见 Python/JS 错误讲解
- 调试心态：AI 辅助不是万能的

**操作步骤：**
1. 你的代码报错，把完整错误信息复制
2. 粘贴给 Claude："帮我看看这个错误"
3. Claude 解释原因后，让它修复
4. 运行确认修复成功

**常见问题：**
- Q: 同样的错误修完又出现？A: 可能需要从根本上重构
- Q: Claude 修错了？A: 用 /undo 撤销，或手动回滚

**练习题：**
1. 故意写一个有 bug 的代码
2. 让 Claude 帮你找出来并修复

---

### 第九章：代码审查和优化（20 分钟）

**学习目标：** 学会让 Claude 做代码审查

**前置知识：** 有代码仓库

**内容大纲：**
- 代码审查是什么，为什么重要
- 让 Claude 审查自己的代码
- 常见代码问题：命名、重复代码、安全隐患
- 优化建议：性能、可读性、架构

**操作步骤：**
1. 问 Claude："请审查这个文件的代码问题"
2. 问："有哪些地方可以优化？"
3. 逐个讨论每个问题
4. 让 Claude 帮你优化

**常见问题：**
- Q: Claude 说的对不对？A: 你是最终决策者，保持批判思维
- Q: 优化建议太多了？A: 优先处理高风险问题

**练习题：** 找一段旧代码让 Claude 审查，并实施它的优化建议

---

### 第十章：Git 操作辅助（20 分钟）

**学习目标：** 学会让 Claude 辅助 Git 操作

**前置知识：** 知道 Git 是什么（不知道也没关系，会抄命令就行）

**内容大纲：**
- Git 基础：commit / push / pull / branch
- 让 Claude 帮你写 commit message
- 让 Claude 帮你处理 merge 冲突
- PR 描述怎么写

**操作步骤：**
1. 修改代码后，问 Claude："帮我看看这些修改"
2. 问："帮我写一个 commit message"
3. 如果有冲突，把冲突信息粘贴给 Claude
4. 问："这个冲突怎么解决？"

**常见问题：**
- Q: merge 冲突太复杂？A: 让 Claude 先解释冲突是什么，再决定怎么合并
- Q: 误操作了？A: `git reflog` 可以找回之前的版本

**练习题：**
1. 修改文件，用 Claude 帮你写 commit message
2. 制造一个 merge 冲突，让 Claude 帮你分析

---

### 第十一章：CLAUDE.md - 给 AI 写说明书（15 分钟）

**学习目标：** 学会创建项目规范文件，让 AI 更懂你的项目

**前置知识：** 有代码项目

**内容大纲：**
- 什么是 CLAUDE.md
- 什么时候需要 CLAUDE.md
- 怎么写项目说明（语言、架构、约定）
- 实际案例讲解

**操作步骤：**
1. 在项目根目录创建 `CLAUDE.md`
2. 写入项目名称、描述、技术栈
3. 写入代码规范（如：使用中文注释）
4. 写入常用命令

**常见问题：**
- Q: 一定要写吗？A: 不是，但写了 Claude 表现更好
- Q: 写在哪里？A: 项目根目录

**练习题：** 给你现有项目创建一个 CLAUDE.md

---

### 第十二章：日常工作流实战（30 分钟）

**学习目标：** 整合前面所学，体验完整工作流

**前置知识：** 学完前十一章

**内容大纲：**
- 场景一：接需求 → 写代码 → 自测 → 提交 PR
- 场景二：接手旧项目 → 理解代码 → 修 bug → 提交
- 场景三：代码审查 → 提出修改 → 优化 → 完成

**操作步骤：**
1. 选择一个简单需求
2. 和 Claude 一起完成全流程
3. 记录遇到的问题和解决方法

**常见问题：**
- Q: 遇到不会的步骤？A: 回到对应章节复习

**练习题：** 从 GitHub 找一个简单的开源项目，完整走一遍修改流程

---

### 第十三章：继续学习之路（10 分钟）

**学习目标：** 知道接下来学什么

**前置知识：** 学完前十二章

**内容大纲：**
- 官方文档阅读指南
- 进阶话题：MCP、Agent 模式、API 集成
- 推荐学习路径
- 资源链接

**常见问题：**
- Q: 忘记了某章内容？A: 随时回来查
- Q: 想学更深入的？A: 查看官方文档
