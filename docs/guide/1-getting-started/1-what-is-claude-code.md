# 第一章：Claude Code 是什么

::: tip 学习目标
学完这章，你会理解 Claude Code 能做什么，不能做什么。
:::

## Claude Code 是命令行工具，不是网页聊天

Claude Code 是一个运行在**终端/命令行**里的工具。你通过打字和它对话，它帮你读写代码。

这和网页版的 Claude（claude.ai）不一样：
- **Claude.ai**：在浏览器里聊天，适合问答、写作、分析
- **Claude Code**：在你的电脑里工作，直接读写你的代码文件

## Claude Code 能做什么？

Claude Code 是一个 AI 编程助手，但它能做的事远不止编程。

### 编程相关

- **读代码**：帮你理解一个陌生项目的结构
- **写代码**：帮你创建新文件或修改现有代码
- **解释代码**：用自然语言解释代码在做什么
- **调试问题**：帮你找出 bug 并修复
- **审查代码**：给你代码优化建议
- **辅助 Git**：帮你写 commit message、处理合并冲突

### 文档编辑

Claude Code 擅长处理各种文档工作：

- **Word 文档**：帮你写报告、写文档、润色文字、总结内容
- **Excel 表格**：帮你分析数据、写公式、生成图表、分析趋势
- **PPT 制作**：帮你规划演示结构、写内容、调整格式
- **Markdown 写作**：写博客、写文档、写邮件（Claude Code 直接支持 .md 格式）

### 日常重复性工作

Claude Code 还可以帮你自动化许多日常琐事：

- **批量重命名文件**：按规则批量修改文件名
- **整理文件夹**：自动归类、移动、清理重复文件
- **生成批量文本**：批量生成报告、邮件、模板内容
- **数据格式转换**：把 CSV 转成 JSON、把 Excel 转成数据库格式
- **日志分析**：帮你从大量日志中提取关键信息
- **定时任务**：结合 Cron 定时运行Claude Code的工作

::: tip 小技巧
由于 Claude Code 能直接读写你的电脑文件，它特别适合需要**批量处理**或**自动化**的任务。相比网页版 Claude，它更适合处理需要多步骤协作的工作。
:::

## Claude Code 不能做什么？

它不能替你做所有事：

- **不能替你做决定**：最终决策权在你手里，Claude 只能提供建议
- **不会读心术**：你需要清楚地描述你要什么
- **批量操作需要你的确认**：虽然能处理大量文件，但每个操作都需要你确认
- **复杂 Excel/PPT 有一定限制**：能做基本编辑，但非常复杂的格式和宏可能需要你进一步调整

## 和 ChatGPT / Copilot 的区别

| 工具 | 特点 | 适合场景 |
|------|------|---------|
| ChatGPT | 网页聊天，什么都能问 | 通用问答、写文章、分析数据 |
| Copilot | IDE 插件，边写边补全 | 写代码时自动补全 |
| Claude Code | 命令行工具，深入项目 + 批量自动化 | 理解整个项目、文件整理、文档批量生成 |

## 常见问题

**Q: Claude Code 要钱吗？**

A: Claude Code 本身免费，但使用 Claude 的 API 需要付费。新用户有免费额度，初期够用。

**Q: 不会命令行能学吗？**

A: 当然可以！教程会从零教你基本的终端命令。

**Q: Claude Code 能帮我做 Word、Excel、PPT 吗？**

A: 可以！Claude Code 能读写这些文件，帮你写内容、分析数据、规划结构。但要注意：复杂的格式和宏可能需要你进一步调整。更多细节请参考「文档编辑」章节。

**Q: Claude Code 能做日常自动化吗？**

A: 可以！比如批量重命名文件、整理文件夹、转换数据格式、分析日志等。Claude Code 能直接操作你的文件系统，非常适合需要多步骤协作的自动化任务。
