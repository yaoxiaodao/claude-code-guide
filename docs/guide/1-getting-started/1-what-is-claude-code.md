# 第一章：Claude Code 是什么

::: tip 学习目标
学完这章，你会理解 Claude Code 能做什么，不能做什么。
:::

## Claude Code 是命令行工具，不是网页聊天

Claude Code 是一个运行在**终端/命令行**里的工具。你通过打字和它对话，它帮你读写代码。

这和网页版的 Claude（claude.ai）不一样：
- **Claude.ai**：在浏览器里聊天，适合问答、写作、分析
- **Claude Code**：在你的电脑里工作，直接读写你的代码文件

## Claude Code 能做什么？

Claude Code 是一个 AI 编程助手，它可以：

- **读代码**：帮你理解一个陌生项目的结构
- **写代码**：帮你创建新文件或修改现有代码
- **解释代码**：用自然语言解释代码在做什么
- **调试问题**：帮你找出 bug 并修复
- **审查代码**：给你代码优化建议
- **辅助 Git**：帮你写 commit message、处理合并冲突

## Claude Code 不能做什么？

它不能替你做所有事：

- **不能替你运行代码**：Claude 写的代码需要你确认后手动运行
- **不能直接访问互联网**：它只能读写你本地的文件
- **不会读心术**：你需要清楚地描述你要什么

## 和 ChatGPT / Copilot 的区别

| 工具 | 特点 | 适合场景 |
|------|------|---------|
| ChatGPT | 网页聊天，什么都能问 | 通用问答、写文章 |
| Copilot | IDE 插件，边写边补全 | 写代码时自动补全 |
| Claude Code | 命令行工具，深入项目 | 需要理解整个项目时 |

## 常见问题

**Q: Claude Code 要钱吗？**

A: Claude Code 本身免费，但使用 Claude 的 API 需要付费。新用户有免费额度，初期够用。

**Q: 不会命令行能学吗？**

A: 当然可以！教程会从零教你基本的终端命令。
